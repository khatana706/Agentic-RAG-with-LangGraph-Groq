# Agentic-RAG-with-LangGraph-Groq
This repository demonstrates a complete Agentic RAG (Retrieval-Augmented Generation) pipeline
using:
LangGraph – for agentic workflows
Groq – for ultra-fast inference
Qwen 3 32B – LLM used as the agent
Tool routing, query rewriting, document grading, and final answer generation.
